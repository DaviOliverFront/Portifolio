## 📌 Sobre o projeto

Este repositório guarda o código do **meu portfólio pessoal**, a minha vitrine na web! 🚀

A ideia é simples: reunir em um só lugar quem eu sou, as tecnologias que uso no dia a dia e os projetos que saíram do papel e ganharam vida em código. O site foi construído do zero, com foco em **layout responsivo**, **visual limpo** e **navegação tranquila**, funcionando bem tanto no computador quanto no celular 📱💻.

🔗 **Acesse agora:** [davioliverfront.github.io/Portifolio](https://davioliverfront.github.io/Portifolio/)

## 🧰 Tecnologias utilizadas

O portfólio foi feito com uma stack front-end enxuta e direta ao ponto:

- 🟠 **HTML5** — estrutura semântica das páginas
- 🔵 **CSS3** — estilização personalizada e ajustes finos de layout
- 🟣 **Bootstrap 5** — grid, componentes e responsividade
- 🐙 **Git & GitHub** — versionamento do código
- 🌍 **GitHub Pages** — hospedagem gratuita do site

> 💡 Além disso, no dia a dia eu também trabalho com **JavaScript**, **React.js**, **Flutter**, **PHP**, **MySQL** e **Figma**.

## 🚀 Como rodar o projeto localmente

É um site estático, então não tem segredo! 😄

```bash
# 1. Clone o repositório
git clone https://github.com/DaviOliverFront/Portifolio.git

# 2. Entre na pasta do projeto
cd Portifolio

# 3. Abra o index.html no navegador
```

💡 **Dica:** se você usa o VS Code, a extensão **Live Server** deixa o desenvolvimento bem mais gostoso, com recarregamento automático a cada alteração.
